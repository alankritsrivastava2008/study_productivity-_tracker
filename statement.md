# Study productivity Tracker 

# problem statement
Student sometime find it difficult to record study time and compare them with other subject's study session . This program solve that problem by recording each subject study session

# Scope of the project 
The Study Productivity Tracker is a Python app created to monitor and track students’ study time. It enables users to open studysessions, type the subjects they are studying, calculate how
long they have studied for, view study time statistics, see their study reports, and much more. The program utilizes a terminal window as its primary interface, and it stores information
 temporarily in a local session before permanently saving it in a file. There are several features that can be added to this application, such as storing data permanently in a file, having
  having daily statistics, setting goals for each study session, and many more.

# Target User
1. Student
2. people with weak focus
